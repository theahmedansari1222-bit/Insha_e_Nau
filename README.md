# انشائے نو

نئے لکھاریوں کی اردو تحریروں کا پلیٹ فارم۔ ٹیک: `Astro` + `Cloudflare` + `Supabase`۔

**موجودہ حالت: ورژن 0.2 (صرف پڑھنے والی سائٹ)۔** فارم اور ایڈمن اگلے ورژنوں میں آئیں گے۔

## پہلی بار چلانے کے مرحلے

### 1) سپابیس
1. supabase.com پر نیا پروجیکٹ بنائیں۔
2. `SQL Editor` میں پہلے `supabase/001_tables.sql`، پھر `supabase/002_security.sql` پیسٹ کر کے چلائیں۔
3. `Project Settings → API` سے دو چیزیں نوٹ کریں: پروجیکٹ کا پتا (URL) اور عوامی کنجی (publishable / anon)۔

### 2) کوڈ گِٹ ہب پر
- نیا نجی ریپو بنائیں اور اس فولڈر کی تمام فائلیں (فولڈروں سمیت) اس میں رکھیں۔
- `wrangler.jsonc` میں پروجیکٹ کا پتا اور عوامی کنجی پہلے سے بھری ہوئی ہیں۔
- **خفیہ کنجی (`secret` / `service_role`) کسی فائل میں کبھی نہ لکھیں۔**

### 3) کلاؤڈ فلیئر
1. Cloudflare ڈیش بورڈ → `Workers & Pages` → نیا پروجیکٹ → گِٹ ہب ریپو جوڑیں۔
2. Build command: `npm run build`
3. Deploy command: `npx wrangler deploy`
4. نوڈ ورژن کی فائل (`.nvmrc`) ریپو میں موجود ہے۔ بلڈ نہ چلے تو `Settings → Build` میں `NODE_VERSION` کی قدر `22` رکھیں۔
5. جب ایڈمن کا حصہ آئے گا تو `Settings → Variables and Secrets` میں خفیہ کنجی `SUPABASE_SECRET_KEY` کے نام سے ڈالی جائے گی۔

(مینو کے نام وقت کے ساتھ تھوڑے بدل سکتے ہیں۔)

## ڈھانچہ

```
src/pages/      صفحے (ہر فائل ایک پتا)
src/components/ چھوٹے اجزا
src/layouts/    مشترک ڈھانچہ
src/lib/        مددگار کوڈ (ڈیٹا، اردو کی صفائی، محفوظ متن)
src/styles/     ڈیزائن
supabase/       ڈیٹا بیس کی فائلیں
public/         جوں کی توں جانے والی فائلیں
```

## معلوم کمیاں (اگلے حصوں میں)
- واٹس ایپ کے لیے طے شدہ تصویر `public/default-card.jpg` ابھی موجود نہیں۔
- فونٹ ابھی گوگل سے آ رہے ہیں۔
- تحریر بھیجنے کا فارم، نجی لنک، ایڈمن، رابطہ، پسند، اشتہار کی جگہ۔
